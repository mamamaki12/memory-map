# Memory Map
スマートフォンで写真を撮り、その場所に写真付きピンを残す地図アプリです。ビルドやAPIキーは不要です。

## 使い方
1. HTTPSで公開されたページをスマートフォンで開きます。
2. 「写真を撮る」を押して撮影します。端末によっては画像選択画面が開きます。
3. 位置情報を許可し、写真・場所・ひとことを確認して保存します。
4. 写真付きピンや一覧から写真を開けます。

位置情報が利用できない場合は「地図で場所を選び直す」から地図をタップして保存できます。写真のEXIF位置情報は読み取りません。画像選択の場合も選択時の現在地を使用するため、必要に応じて場所を修正してください。

## GitHub Pagesで公開
リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択し、ブランチを **main**、フォルダを **/(root)** にして保存してください。
公開先は通常 https://mamamaki12.github.io/memory-map/ です。設定が完了するまでは公開されません。

ローカルでは `python -m http.server 8000` などで配信し、http://localhost:8000 を開きます。スマートフォンの位置情報にはHTTPSが必要です。

## 保存とプライバシー
- 写真と位置情報はIndexedDBに保存し、アプリのサーバーにはアップロードしません。
- 別端末・別ブラウザとは同期されません。ブラウザのデータ削除で写真も失われます。
- 写真は長辺1600px以下のJPEGに変換して保存します。元画像は変更しません。
- 「バックアップ」で画像を含むJSONを書き出せます。現時点でJSONの復元UIはありません。写真の個別ダウンロードにも対応しています。
- 地図タイルはOpenStreetMap、地図ライブラリはunpkgから取得します。これらの外部サービスにIPアドレスなどの通信情報が送信されます。
- 地図の表示にはインターネット接続が必要です。
