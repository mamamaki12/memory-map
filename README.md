# Memory Map
React + Vite + Leafletで作る写真地図アプリです。サーバー処理・ログインはありません。

## 開発
Node.js 22.12以上（推奨24）で実行します。
```sh
npm install
npm run dev
npm test
npm run build
```
ビルド確認は `npm run preview` です。

## GitHub Pages
Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。
mainへのpushでテスト・ビルド・公開が実行されます。手動実行はActionsの「Build and deploy Memory Map」→「Run workflow」です。
公開先: https://mamamaki12.github.io/memory-map/
Viteのbaseは `/memory-map/` です。リポジトリ名を変える場合は調整してください。

## 機能
- 写真撮影・位置情報取得・写真ピン（ズームに合わせてサイズ変更）。スマホでは「カメラで撮る」と「アルバムから選ぶ」を選べます（パソコンでは写真ファイルを選ぶ画面を直接開きます）。写真が1枚もないときは、地図の上に「何をする地図か」と始め方を出します
- 現在地の青丸と精度範囲、地図で保存場所の手動選択（保存画面では場所を小さな地図で表示。選び直すときは地図を動かして印を合わせ、「ここに決める」で決定）
- 写真一覧・拡大・削除（取り消せない旨を書いた確認画面で「削除する」を押したときだけ消えます）・個別ダウンロード
- 上のバーの「写真｜攻略」で、写真の地図と全国攻略の地図を切り替え（いま出ている方が緑）。写真の枚数は、友達の写真があるときは「自分 N・友達 M」と出します
- スマホの思い出一覧はタップ／スワイプで開閉
- 設定内のJSONバックアップとインポート
- ホーム画面への追加案内とアプリアイコン

## バックアップと復元
設定 →「バックアップ」で写真・場所・ひとこと・日時をJSONに保存します。
設定 →「バックアップをインポート」で、このアプリが出力したversion 1のJSONを選びます。旧版のバックアップも使えます。
既存写真は削除・上書きせず、同じIDの写真はスキップします。新規分だけ追加し、結果の枚数を表示します。
形式・座標・日時・画像を検証してから1トランザクションで復元します。途中で失敗した場合、新規追加分も取り消します。
インポートは100MB／10,000枚までです。ファイルを開く端末に十分な空き容量が必要です。
バックアップのファイル名には日付が入ります（例：memory-map-backup-2026-11-04.json）。
設定には前回のバックアップ日時と、そのあとに保存した写真の枚数を表示します。バックアップしていない写真が10枚増えるごとに、保存したときのメッセージでお知らせします（記録はこのブラウザの中だけです）。

## ホーム画面への追加
通常のブラウザ表示では追加案内が出ます。「×」でそのページを開いている間は閉じられます。
対応ブラウザでは「追加する」からインストールできます。それ以外は「追加方法」の案内を使ってください。
iPhoneでは共有メニュー →「ホーム画面に追加」を使います。項目がない場合はSafariで開いてください。
standalone表示（iOSのnavigator.standaloneも含む）で起動した場合は案内を表示しません。
追加済みかどうかを通常のブラウザタブから完全には判定できないため、追加済みでもブラウザで開くと案内が出る場合があります。
地図のオフライン利用は未対応です。

## データ
IndexedDBの名前 `memory-map`、バージョン1、ストア `photos` は旧版と同じです。
写真は長辺1600px以下のJPEGに変換し、この端末のブラウザ内に保存します。サーバーや他端末とは同期しません。
ブラウザのデータ削除で写真は消えます。ホーム画面からの起動時に保存領域が異なる端末では、バックアップのインポートで移してください。
写真を保存すると、空き容量が少なくなっても写真を消さないようブラウザにお願いします（navigator.storage.persist）。ブラウザによっては許可されません。
アルバム（パソコンでは写真ファイル）から選んだ写真は、JPEGのEXIFに撮影場所（GPS）があればその場所を使います。撮影場所の情報がない写真（PNG・位置を記録していない写真など）とカメラで撮った写真は、選択時の現在地を使います。どちらを使ったかは保存画面に表示されます。必要なら地図で変更してください。
カメラ・位置情報にはHTTPS（開発時はlocalhost）が必要です。地図タイルの取得にはインターネット接続が必要です。
通信が切れると知らせ、つながり直したときに読み込めなかった地図を自動で読み込み直します。
位置情報が許可されていないとき・取得に時間がかかるときは、理由と直し方を表示します。精度が100mより粗いときは、保存画面で場所の確認をすすめます。
ReactとLeafletはビルドに含まれ、地図タイルはCARTO Voyager（キー未設定時はOpenStreetMap）から取得します。

## テスト
`npm test` で保存・再読込・削除・中断と、写真のEXIFから撮影場所を読む処理（壊れたデータを含む）と、バックアップの変換・不正データの拒否・重複処理・途中失敗時のロールバックを確認します。
友達交換のSQL（supabase/）は、試験用のPostgres（PGlite）で実行して、他人の写真・友達コードが読めないこと、申請の承認、保存の上限などを確認します。
端末ごとのカメラ・権限・ホーム画面へのインストール操作は実機確認が必要です。

## 友達交換
友達コードで申請・承認し、選んだ写真を友達の地図に共有できます。共有にはSupabaseの接続設定が必要です。設定手順は [supabase/README.md](supabase/README.md) を参照してください。未設定時は友達画面に接続待ちを表示します。

## 地図のデザイン（CARTO Voyager）
写真の地図・全国攻略の両方でVoyagerを使用します。
1. https://carto.com/basemaps/apikey/ でBasemaps用のAPIキーを取得します。
2. キーの利用先を `mamamaki12.github.io` に制限してください。
3. `src/map-config.json` の `cartoApiKey` にブラウザ用キーを設定してmainに反映します。
4. GitHub Actionsの公開完了後にアプリを再読み込みします。

ブラウザ用キーは公開サイトから参照されます。管理用トークン・秘密鍵は設定しないでください。
キー未設定時は従来のOpenStreetMapを表示します。設定済みキーのエラー時は無断で別サービスへ切り替えません。
CARTOとOpenStreetMapの出典表示は地図内に保持します。
