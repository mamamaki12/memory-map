# 友達共有の接続設定
この設定を完了するまで、友達画面は「共有サーバーの接続設定がまだ完了していません」と表示します。端末内保存は引き続き使えます。

1. Supabaseで自分のプロジェクトを作成します。
2. SQL Editorでsetup.sqlを一度実行します。非公開StorageとRLSを作成します。
3. Authentication → URL ConfigurationでSite URLとRedirect URLに https://mamamaki12.github.io/memory-map/ を登録します。
4. Email認証を有効にします。公開運用で不特定の友達にメールを送る場合はSMTPを設定してください。標準メールサービスは送信先・回数が制限される場合があります。
5. public/friends-config.jsonのurlにProject URL、publishableKeyにpublishableキー（またはanonキー）を入れてmainに反映します。これらは公開用設定です。service_roleやsecretキーは絶対に入れません。
6. 自分と友達の2つのアカウントでログインして、コード交換・承認・写真共有を確認します。

## 使い方
「友達」→メールでログイン→表示名を保存→自分の友達コードを相手に渡します。相手が申請し、自分が承認すると友達になります。
「友達に共有」を選んだ写真と撮影場所だけが、承認済みの友達全員に公開されます。
「共有を停止」「友達解除」で新たな画像取得を停止します。相手が既にダウンロードした写真までは削除できません。
共有写真は200件まで新しい順に表示します。友達画面の「写真・申請を更新」、または表示中の60秒ごとの更新で取得します。
友達の写真を端末内バックアップに自動追加したり、他人の写真を削除したりしません。
ログアウトすると友達の写真を地図から取り除きます。

## 検証
GitHub ActionsはReactのビルドと既存テストを実行します。Supabaseが未接続の状態では、メール配送、SQL実行、2アカウント間のRLSは検証できません。
公開前に未ログイン・申請前・申請中・承認後・解除後でメタデータとStorageの取得可否を確認してください。
